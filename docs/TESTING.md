## 运行测试

ResponsiveLayoutTest 含 6 项测试：手机竖屏、手机横屏、599dp 边界、600dp 平板竖屏、平板横屏资源优先级、实际 Activity 中控件可见性及窗口边界。

本机缺少 Android Emulator hypervisor driver。使用官方 API 24 镜像的软件模拟尝试启动后，Windows 模拟器进程以 0xC0000005（-1073741819）退出，未完成启动。因此本机仪器化测试与截图未通过验证，不能将仅编译成功视为运行成功。
